# 🧟 ZOMBIE APOCALYPSE - GAME PROJECT

A survival action game built with HTML, CSS, and JavaScript. Fight zombies, survive waves, upgrade weapons, and dominate the apocalypse.

---

## 🚀 FEATURES

### 🎮 Gameplay Features
- Zombie wave survival system  
- Health & stamina mechanics  
- Weapon switching system  
- Score tracking system  
- Level progression system  
- Boss fight encounters  

### 🧠 AI & LOGIC
- Smart zombie movement AI  
- Increasing difficulty scaling  
- Random spawn system  
- Damage calculation system  

### 🔫 COMBAT SYSTEM
- Melee attacks (knife, bat)  
- Ranged weapons (gun, shotgun)  
- Reload system  
- Ammo management  

### 🎨 UI / UX
- Responsive game UI  
- Health bar & stamina bar  
- Score dashboard  
- Start / Pause / Game Over screens  

### 🎧 AUDIO SYSTEM
- Background survival music  
- Zombie sound effects  
- Gunshot effects  
- UI click sounds  

### 📦 ASSETS SYSTEM
- Image-based sprites  
- Background maps  
- Sound FX folder  
- Modular asset loading

## 🌐 HOW TO HOST ON GITHUB PAGES

1. Go to your GitHub repository  
2. Click Settings  
3. Scroll to Pages  
4. Select branch: main / root  
5. Save  
6. Your game will be live at:  
https://username.github.io/ZOMBIE-APOCALYPSE/

---

## 📥 HOW TO DOWNLOAD PROJECT

git clone https://github.com/USERNAME/ZOMBIE-APOCALYPSE.git  

Open index.html in browser or use Live Server in VS Code.
